절약이라고 하면 커피 한 잔, 배달 한 번을 참는 일을 먼저 떠올립니다. 하지만 의지로 줄이는 변동비는 오래 가기 어렵습니다. 반면 **고정비는 한 번 손보면 그다음 달부터 아무 노력 없이 효과가 이어집니다.** 통신 요금제를 바꾸는 데는 한 시간이 걸리지만 그 효과는 3년 동안 매달 이어집니다. 이 글은 고정비를 한꺼번에 정리하려고 애쓰는 대신 **한 주에 한 곳씩, 6주짜리 프로젝트**로 나눠 진행하는 방법을 제안합니다. 모든 절감액은 설명용 가정입니다.

## 시작 전: 숫자 모으기(15분)

최근 두 달의 카드 명세서와 통장 출금 내역에서 매달 같은 날 같은 금액으로 나가는 항목만 추려 한 장에 모읍니다.

| 항목 | 월 금액 | 마지막으로 점검한 시점 | 줄일 가능성(상/중/하) |
|---|---|---|---|
| 구독 서비스 | | | |
| 통신비 | | | |
| 보험료 | | | |
| 교통·차량 | | | |
| 주거·대출 이자 | | | |
| 기타 자동결제 | | | |

가능성 열에서 **'상'이 붙은 곳부터 6주 순서**를 정합니다. 아래는 일반적으로 쉬운 곳부터 어려운 곳으로 나열한 순서이니 참고만 하세요.

## 6주 프로젝트

**1주 차: 구독 서비스(소요 약 30분).** 영상·음악·클라우드·앱 구독을 전부 적고, 최근 30일 안에 쓴 적이 있는지 표시합니다. 안 쓴 것은 해지, 쓰는 것은 가족 공유나 묶음 상품이 있는지만 확인합니다. 해지 전에 연간 결제가 남아 있는지 환불 규정부터 봅니다. 가정 절감액: 월 2.5만 원.

**2주 차: 통신비(약 1시간).** 지난 3개월 평균 데이터 사용량과 요금제를 비교합니다. 사용량이 한참 모자란다면 한 단계 낮은 요금제로 바꾸고, 약정이 끝났다면 다른 통신 사업자·알뜰폰의 요금제를 같은 품질 조건으로 비교합니다. 위약금과 결합 할인 해지 여부는 꼭 확인합니다. 가정 절감액: 월 3만 원.

**3주 차: 자동결제 정리(약 30분).** 헬스장, 정기배송, 앱 내 결제, 미사용 멤버십을 카드 명세서의 정기 결제 표시로 찾아 정리합니다. 가정 절감액: 월 2.5만 원.

**4주 차: 보험료(약 2시간).** 중복 보장과 과다 가입을 점검하는 단계입니다. 순서는 [보험 점검 5단계](/ko/guides/insurance-checkup-five-steps)를 그대로 따르면 됩니다. 새 보험이 시작되기 전에 기존 보험을 해지하지 마세요. 가정 절감액: 월 7만 원.

**5주 차: 교통·차량(약 1시간).** 월 주행거리 대비 보유 비용 합계를 계산합니다. 계산 방법은 [자동차 한 대의 진짜 비용](/ko/guides/car-ownership-cost-vs-transit-fire-impact)에 정리했고, 차가 없다면 대중교통 정기권·환급형 혜택이 내 이용 패턴에 맞는지 점검합니다. 가정 절감액: 월 5만 원.

**6주 차: 주거·대출(약 2시간).** 월세나 관리비는 줄이기 어렵지만 대출이 있다면 금리를 낮출 여지가 있는지 확인합니다. 점수 관리와 갈아타기 조건은 [신용점수와 대출 금리](/ko/guides/credit-score-and-loan-interest-basics)에서 설명했습니다. 가정 절감액: 월 5만 원.

여섯 곳의 합은 월 25만 원입니다. 이 상태에 [가계부 없이 3개월 지출 파악하기](/ko/guides/three-month-spending-audit-without-budget-app)에서 찾는 소액 결제 정리 약 5만 원을 더해 월 30만 원 절감이라고 가정하겠습니다.

## 줄인 돈이 FIRE를 얼마나 당길까요

월 실수령 350만 원, 저축 105만 원(저축률 30%)인 사람이 월 30만 원 또는 45만 원을 줄였다고 가정합니다(실질 수익률 5%, 인출률 4%, 연 단위 적립, 저축 0원 시작).

| 시나리오 | 월 저축 | 저축률 | FIRE 도달 기간 | 현재 대비 |
|---|---|---|---|---|
| 현재 | 105만 원 | 30.0% | 약 28.0년 | — |
| 월 30만 원 절감 | 135만 원 | 38.6% | 약 22.5년 | 약 5.5년 단축 |
| 월 45만 원 절감 | 150만 원 | 42.9% | 약 20.1년 | 약 7.9년 단축 |

여기서 눈여겨볼 점은 **효과가 두 번 나타난다**는 것입니다. 첫째, 저축이 늘어 도달 기간이 줄어듭니다. 둘째, 월 생활비가 줄어서 필요한 목표 자산도 줄어듭니다. 월 30만 원은 연 360만 원이고, 이를 25배(인출률 4%)로 환산하면 목표 자산이 9,000만 원 낮아집니다. 같은 30만 원을 소득을 더 벌어서 얻을 때는 목표 자산이 그대로이므로 절감이 훨씬 강력합니다. 두 방법의 차이는 [저축률 목표표](/ko/guides/savings-rate-target-table-by-income)에서 숫자로 비교합니다.

## 줄인 돈은 반드시 이동시킵니다

절감이 확정된 날 바로 아래 둘 중 하나를 합니다.

- 저축·투자 통장으로 가는 자동이체 금액을 같은 만큼 올립니다.
- 월급 통장을 목적별로 나누는 구조가 없다면 [월급 통장 쪼개기](/ko/guides/salary-account-split-system)부터 정리합니다.

고정비를 다 점검했는데도 줄일 곳이 많지 않다면 소득을 늘리는 쪽도 함께 보세요([부업으로 FIRE 속도 높이기](/ko/guides/side-hustles-to-accelerate-fire)).

## 해지한 뒤 되돌아오지 않게 하는 법

고정비는 시간이 지나면 슬그머니 다시 늘어납니다. 아래 세 가지를 지키면 효과가 오래갑니다.

1. **새 구독이나 요금제가 늘 때는 무엇을 빼고 추가할지 먼저 묻습니다.**
2. **연 1회 점검일(연말정산 시기나 연초)을 달력에 고정합니다.** 오늘 만든 표를 다시 열어 같은 질문을 하면 됩니다.
3. **절감 금액을 눈에 보이는 곳에 기록합니다.** 한 줄 메모만으로도 지속률이 올라갑니다.

내 숫자는 [FIRE 계산기](/ko/calculators)에서 월 저축액을 바꿔 확인해 보세요.

## 해지할지 말지 헷갈릴 때, 회수 개월 수로 판단하기

위약금이나 해지 수수료가 걸려 있으면 줄일지 말지 고민이 길어집니다. 이럴 때는 간단한 계산 하나면 충분합니다.

**위약금(또는 갈아타는 비용) ÷ 매달 아끼는 금액 = 본전을 찾는 개월 수**

예를 들어 통신 요금제를 바꾸면 월 3만 원이 줄지만 위약금이 12만 원이라면 4개월이면 본전입니다. 남은 약정이 4개월보다 길게 남아 있다면 지금 바꾸는 쪽이 이익이고, 약정이 곧 끝난다면 끝나는 날에 맞춰 바꾸는 것이 낫습니다.

같은 방식으로 이렇게도 쓸 수 있습니다.

- **보험:** 해지 환급금이 줄어드는 상품은 절감액보다 손실이 더 클 수 있으므로, 같은 보장의 대체 상품이 시작된 뒤에 해지합니다.
- **헬스장·멤버십:** 환불 가능 금액을 남은 기간으로 나눠 보면 지금 해지할지 끝까지 쓸지가 보입니다.
- **차량·대출:** 갈아타는 비용을 매달 줄어드는 이자로 나눠 회수 기간을 구합니다.

회수 기간이 1년을 넘으면 기회비용까지 따져 봐야 하고, 6개월 이내라면 대체로 바로 움직여도 부담이 적습니다. 고정비 정리의 핵심은 과감한 해지가 아니라 계산이 맞는 것부터 해 나가는 순서입니다.
