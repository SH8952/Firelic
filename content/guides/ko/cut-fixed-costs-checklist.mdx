절약이라고 하면 커피 한 잔, 배달 한 번을 참는 일을 떠올리기 쉽습니다. 그런데 의지력으로 줄이는 변동비는 오래 가기 어렵고, 줄인 만큼 스트레스도 따라옵니다. 반대로 **고정비는 한 번 손보면 이후 매달 자동으로 효과가 이어집니다.** 같은 노력이라면 고정비부터 점검하는 편이 훨씬 효율적입니다. 이 글은 고정비를 여섯 곳으로 나누어 점검 순서를 정리하고, 줄인 금액이 FIRE 도달 기간을 얼마나 당기는지 숫자로 보여 드립니다.

## 먼저 숫자를 한 번에 모읍니다

최근 두세 달의 카드 명세서와 통장 출금 내역을 열어 매달 같은 날짜에 같은 금액으로 나가는 항목을 표로 정리합니다.

| 항목 | 월 금액 | 마지막으로 점검한 시점 | 줄일 수 있는지 |
|---|---|---|---|
| 통신비(휴대폰·인터넷) | | | |
| 구독 서비스 | | | |
| 보험료 | | | |
| 교통·차량 유지 | | | |
| 주거(월세·관리비·대출이자) | | | |
| 기타 자동결제 | | | |

실제로 표를 채워 보면 존재를 잊고 있던 자동결제가 한두 개는 나옵니다. 그것만으로도 첫 수확이 됩니다.

## 점검 순서: 여섯 곳

1. **구독 서비스:** 영상·음악·클라우드·앱 구독을 모두 나열하고 최근 한 달 동안 실제로 사용했는지 확인합니다. 쓰지 않은 것은 해지하고, 자주 쓰는 것만 남깁니다. 가족 공유나 묶음 상품으로 합칠 수 있는지도 봅니다.
2. **통신비:** 현재 요금제의 데이터 사용량과 실제 사용량을 비교합니다. 약정이 끝났다면 요금제를 낮추거나 알뜰폰 등 다른 선택지를 같은 품질 조건으로 비교해 봅니다. 위약금이나 결합 할인 해지 여부는 꼭 확인하세요.
3. **보험료:** 중복 보장과 과다 가입이 있는지 확인하는 것이 핵심입니다. 순서는 [보험 점검 5단계](/ko/guides/insurance-checkup-five-steps)를 그대로 따르면 됩니다. 새 보험이 시작되기 전에 기존 보험을 해지하지 마세요.
4. **교통·차량:** 월 주행거리 대비 자동차 보유 비용(보험, 세금, 주차, 할부, 유류, 정비)을 모두 더해 봅니다. 대중교통 정기권이나 환급형 교통 혜택이 맞는지 점검하고, 차량 보험은 갱신 시점에 조건 비교를 합니다.
5. **주거:** 월세나 관리비는 줄이기 어렵지만 대출이 있다면 금리를 낮출 여지가 있습니다. 점수 관리와 대환은 [신용점수와 대출 금리](/ko/guides/credit-score-and-loan-interest-basics)에서 확인하세요.
6. **기타 자동결제:** 헬스장, 정기배송, 앱 내 결제, 미사용 멤버십 등을 확인합니다. 카드 명세서에서 정기 결제 표시를 필터링하면 빠르게 찾을 수 있습니다.

## 줄인 돈이 FIRE를 얼마나 당길까요

월 실수령 350만 원, 지금 저축이 105만 원(저축률 30%)인 사람이 고정비를 정리했다고 가정해 봅니다. 아래 금액은 설명을 위한 가정이며 실제 절감액은 사람마다 다릅니다. 실질 수익률 5%, 인출률 4%, 저축 0원 시작 기준입니다.

| 시나리오 | 월 저축 | 저축률 | FIRE 도달 기간 | 현재 대비 |
|---|---|---|---|---|
| 현재 | 105만 원 | 30.0% | 약 28.0년 | — |
| 고정비 월 30만 원 절감 | 135만 원 | 38.6% | 약 22.5년 | 약 5.5년 단축 |
| 고정비 월 45만 원 절감 | 150만 원 | 42.9% | 약 20.1년 | 약 7.9년 단축 |

월 30만 원은 1년이면 360만 원이지만, 진짜 효과는 저축률이 올라서 **도달 기간 자체가 줄어든다**는 점입니다. 또한 같은 금액을 줄이면 FIRE 목표 금액(필요 생활비 × 25)도 함께 낮아집니다. 월 생활비가 30만 원 줄면 목표 자산이 7,500만 원 줄어듭니다. 이중 효과를 [FIRE 계산기](/ko/calculators)에서 본인 숫자로 직접 확인해 보세요.

## 줄인 돈은 반드시 이동시킵니다

줄인 금액이 통장에 그대로 남아 있으면 다른 소비로 흘러가기 쉽습니다. 절감이 확정된 날 바로 아래 둘 중 하나를 합니다.

- 저축·투자 통장으로 가는 자동이체 금액을 같은 만큼 올립니다.
- 월급 통장을 목적별로 나누는 구조를 아직 만들지 않았다면 [월급 통장 쪼개기](/ko/guides/salary-account-split-system)부터 정리합니다.

고정비를 점검했는데 크게 줄일 곳이 없다면 소득을 늘리는 쪽을 함께 보는 것도 방법입니다. 소득 확대는 [부업으로 FIRE 속도 높이기](/ko/guides/side-hustles-to-accelerate-fire)를 참고하세요.

## 연 1회 점검 루틴

고정비는 시간이 지나면 다시 늘어납니다. 연말정산 시기나 연초에 한 번씩 위의 표를 다시 채워 보는 것을 습관으로 만들면 절감 효과가 유지됩니다. 새로운 구독이나 요금제가 추가될 때마다 "무엇을 빼고 이것을 추가할까"를 먼저 묻는 규칙도 도움이 됩니다.
